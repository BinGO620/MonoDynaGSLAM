# 三轴框架下的 idea 探索

> 基于用户的方法框架：静态重建 → anti/face dynamic → SLAM BA+渲染
> 参考：MMM 2027 教程 "Optimizing 3D Scene Representations"（压缩/自组织/紧凑表示）
> 文献基础：`data/methods.json`（18 方法）+ 文献全景 agent（25+ 篇）+ codex 对抗审核

## 框架解读

### 三轴 (A, B, C) 与它们的交叉点

```
A: 静态重建效率          B: 动态处理策略
  (压缩/自组织/紧凑表示)     (anti ↔ face)
        │                      │
        └──────────┬───────────┘
                   │
         C: SLAM 双任务
         (跟踪 BA ↔ 建图渲染)
```

**核心洞察**：现有的 dynamic 3DGS SLAM 在三个轴上都有探索，但**没有方法在三轴的交叉点做系统性优化**。具体来说：

| 轴 | 现有工作 | 空白 |
|---|---|---|
| A（静态效率） | MMM'27 Tutorial: HAC/Compact3D/Scaffold-GS/FLAS/SOG | 全在离线静态场景，未用于在线 SLAM |
| B（动态处理） | anti: WildGS/Dy3DGS/DAGS/GGD; face: D2GSLAM/Flow4DGS | 硬编码一种模式，不自适应切换 |
| C（SLAM双任务） | BA 跟踪 + 渲染建图（MonoGS 范式） | 动态处理未独立区分 BA 和渲染的响应策略 |

## 候选切入点（三轴交叉）

### 切入点 1: A × B × C — 紧凑动态表示 + 自适应模式切换

**核心**：把 MMM'27 教程的 3DGS 紧凑表示（自组织/压缩）引入动态 SLAM，同时让 SLAM 的跟踪 BA 和建图渲染采用不同的动态处理策略。

**为什么是 gap**：
- 所有动态 3DGS SLAM 使用标准 3DGS 表示（无压缩/紧凑化）
- 所有方法在 BA 和渲染中使用相同的动态策略（要么 anti 到底，要么 face 到底）
- 实际上：BA 需要静态一致性（anti-dynamic 更优），渲染需要视觉完整性（face-dynamic 更优）

**方法思路**：
1. **紧凑静态表示**：借鉴 Scaffold-GS/SOG 的 anchor/sparse 结构，仅对静态区域使用紧凑表示，动态区域用全参数高斯
2. **双任务解耦**：BA 跟踪使用 anti-dynamic 策略（权重/掩码抑制动态），渲染建图使用 face-dynamic 策略（显式建模动态物体）
3. **动态区域紧凑化**：对 face-dynamic 的 4D 高斯使用低秩分解/变形场压缩

### 切入点 2: B × C — 动态状态感知的 BA 渲染分治

**核心**：SLAM 的跟踪和建图两个任务对动态的容忍度不同，分别设计最优策略。

**方法思路**：
1. **BA 跟踪层**：使用 lightweight anti-dynamic（纯几何一致性权重，如光流-重投影残差），目标是稳定位姿
2. **渲染建图层**：使用 face-dynamic（4D 高斯/变形场），目标是视觉质量
3. 两个任务共享同一高斯表示但使用不同的 loss 权重和动态 mask

### 切入点 3: A × C — 压缩感知的 SLAM 关键帧/高斯管理

**核心**：把 FLAS/SOG 的排序和紧凑化思想应用到 SLAM 的在线高斯管理中。

**方法思路**：
1. 在线高斯排序/压缩（类似 FLAS），减少长期 SLAM 的地图膨胀
2. 动态高斯和静态高斯分别维护不同的压缩策略
3. 关键帧选择考虑高斯紧凑度（不仅是视差）

## 我推荐优先深入的切入点

**切入点 1（A × B × C）** 是对三轴最完整的覆盖，且与现有工作（D2GSLAM、DAGS-SLAM、GGD-SLAM）差异化明显。关键验证问题：

1. BA 跟踪用 anti 策略、渲染用 face 策略——两者是否冲突？
2. 紧凑静态表示在在线 SLAM 中能否维持实时性？
3. 双任务分治能否带来量化增益（ATE + 渲染质量）？

## 验证路径（Phase 0）

在本地 2060 上，用 Bonn 最短序列（balloon 440 帧）测试：
- 控制组：标准 MonoGS + joint anti-dynamic
- 实验组：BA 跟踪用 anti 加权 + 渲染用 face 建模（最简单的版本：静态高斯 + 动态高斯分类）
- 观测指标：ATE 差异、渲染 PSNR 差异、动态区域 ghosting

## 与已有资产的关系

RoGS-SLAM 的可靠性信号（光流-重投影一致性）可复用为 BA 跟踪的 anti-dynamic 权重；D 组件（生命周期）可复用为动态高斯的管理机制。这些都是资产，不进入论文主线叙事。
