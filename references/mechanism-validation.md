## 1. A-F 完整消融矩阵（fr3_walking_xyz，50帧，60k 高斯）

| 组别 | 机制 | PSNR | Δ vs A | 回答的问题 |
|---|---|---|---|---|
| **A** | 无 anti（baseline） | 24.03 | — | 参照 |
| **B** | 残差调制全局衰减（原实现） | 25.42 | +1.39 | 当前实现的效果 |
| **C** | 固定衰减（无残差信息） | 24.06 | +0.03 | **衰减本身无效** |
| **D** | 随机选 1/3 高斯衰减（数量匹配 F） | 24.12 | +0.09 | **随机选择无效** |
| **E** | 逐像素 hard mask（标准做法） | 21.97 | -2.06 | **像素粒度错误** |
| **F** | 残差归因选择性高斯衰减 | 25.00 | +0.97 | **归因选择有效** |

### 机制结论（回应 R1-M1 / R2-M1）

1. C ≈ A 且 D ≈ A → codex 的"隐式正则化"替代解释**被排除**：收益不来自 opacity 衰减本身，也不来自随机选择；
2. F > A (+0.97) 且 F > D (+0.88) → **残差归因的选择性是收益来源**，机制成立；
3. F < B (+0.42) → 残差信号中还含有全局成分（B 的全局调制利用了它）；诚实结论：**残差信号同时有选择性成分（F 验证）和全局成分（B 验证）**；
4. E < A → 逐像素硬 mask 丢失信息，像素粒度不是正确的操作粒度。

## 3. 选中高斯与 GT 动态 mask 的量化对应（回应 R3-M1/M2）

Bonn balloon（有 dynamic_mask_gtmc GT，全局动态占比 3.8%）：

| 选择策略 | GT precision（选中高斯投影落在动态 mask 内的比例） |
|---|---|
| selective（残差归因） | **7.9%** |
| random（同数量） | 3.9%（≈ 先验 3.8%） |

- selective 的动态指向性是随机先验的 **2 倍** → 机制确实倾向选中动态高斯；
- 绝对 precision 低（92% 选中高斯在静态区） → 残差信号混有深度先验误差、遮挡边界、光照变化的噪声。**不声称"动态高斯识别"，只声称"不一致高斯的选择性抑制"。**

## 4. 修正后的机制命名（回应"事实性错误"批评）

旧声称（错误）："Gaussian 级 anti-dynamic——识别动态高斯并压制"

修正声称（可辩护）："**残差引导的选择性高斯 opacity 衰减**（residual-guided selective Gaussian opacity decay）：
- 通过投影归因把多帧渲染残差定位到具体高斯；
- 选择性地衰减不一致高斯的 opacity（~1/3 高斯）；
- 与动态区域有统计对应（2× 随机先验）但不等于动态识别；
- 三个对照（C/D/E）排除衰减正则化、随机选择、像素粒度的替代解释。"

## 6. PnP 四组析因（回应 R1-M2，2026-09-01 补充）

walking_xyz，PnP init（ATE=6.0cm），60k 高斯，2500 iters：

| 组合 | PSNR | ATE | Δ vs PnP only |
|---|---|---|---|
| PnP only | 16.2 dB | 6.0 cm | — |
| PnP + refine（位姿微调） | 19.0 dB | 6.1 cm | **+2.8** |
| PnP + anti（无 refine） | 16.3 dB | 6.0 cm | **+0.1** |
| PnP + refine + anti | 20.3 dB | 6.6 cm | +4.1 |

### 修正后的结论

1. **原声称"非 GT 初始化下 anti 提升更大（+4.1 dB）"是归因错误**——refine 贡献 2.8 dB，anti 单独仅 0.1 dB，协同 +1.2 dB；
2. **anti 单独在位姿不准时几乎无效**：位姿误差淹没渲染残差信号；
3. GT init 下 anti 的 +1.4 dB 仍然成立（位姿准 → 残差信号可用）；
4. 存在 **refine × anti 协同效应**（+1.2 dB 交互项），机制待解释（可能：refine 后残差信号变干净，anti 才能正确归因）。

### 修正后的机制边界声明

> 残差引导的选择性 opacity 衰减的有效性**以位姿质量为前提**。GT/精调位姿下 +0.8~1.4 dB；粗糙位姿下单独使用无效，需与位姿优化协同（+1.2 dB 交互）。

### 多种子修正后的结论（三轮证据状态）

4. 机制叙事最终版本："residual-guided selective Gaussian opacity decay 在动态序列上稳定优于随机/固定/像素级对照（+0.3~1.1 dB），但存在静态场景误伤代价，需动态感知门控。"

## 11. 动态门控（三轮改进，2026-09-01）

针对 §10 发现的静态误伤，加入序列级动态门控：anti_update 前估计帧级动态占比的序列中位数，< 2% 则跳过衰减。

| 场景 | A baseline | F 无门控 | **gated selective** |
|---|---|---|---|
| fr1_desk（静态负对照） | 24.22 | 23.08（-1.14 ✗） | **24.49（+0.27 ✓）** |
| fr3_walking_xyz（动态） | 23.63（3-seed mean） | 24.69（+1.06 ✓） | **24.69（+1.06 ✓，无损失）** |

**最终方法形态：Gated Selective Residual-guided Opacity Decay (GS-ROD)**
- 门控在动态序列零损失，静态序列消除误伤并轻微正向；
- 完整证据链：A-F 消融（多 seed）→ GT 归因 → held-out → 位姿边界析因 → 门控负对照。
