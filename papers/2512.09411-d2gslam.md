# [2512.09411] D2GSLAM: 4D Dynamic Gaussian Splatting SLAM

- **类别**: face-dynamic（static-3D + dynamic-4D 复合表示）
- **Venue**: arXiv 2025（IEEE T-RO 系投稿版）
- **作者**: Siting Zhu, Yuxiang Huang, Wenhua Wu, Chaokang Jiang, Yongbo Chen, I-Ming Chen, Hesheng Wang (SJTU / Bosch / NTU)
- **来源**: 本地 `/data/arxiv_papers/2512.09411.md`

## 核心机制

1. **几何提示动态分离**：利用高斯表示与场景几何的几何一致性获取粗略动态区域，作为 prompt 精化 motion mask；
2. **静态-动态复合表示**：静态 3D 高斯 + 动态 4D 高斯，统一优化，支持静态↔动态状态迁移；
3. **渐进位姿精化**：同时利用静态几何多视角一致性与动态物体运动信息跟踪；
4. **运动一致性 loss**：利用物体运动时间连续性做准确动态建模。

## 关键点

- **face-dynamic 代表**：显式建模动态物体的时空运动（4D 高斯），跟踪利用运动信息而非仅规避；
- 与 anti-dynamic 的本质区别：动态物体的运动被编码进表示并可渲染；
- 对 RoGS-SLAM 的参考意义：face-dynamic 是路线对照（我们不做动态重建），但其动态-静态分离（几何一致性）与我们同源，方法可互相借鉴。
