# [2504.03886] WildGS-SLAM: Monocular Gaussian Splatting SLAM in Dynamic Environments

- **类别**: anti-dynamic（不确定性加权）
- **Venue**: CVPR 2025 (Poster)
- **作者**: Zheng*, Zhu*, Bieri, Pollefeys, Peng, Armeni (Stanford / ETH / Microsoft)
- **代码**: https://github.com/GradientSpaces/WildGS-SLAM（本地 `/data/WildGS-SLAM`）
- **来源**: 联网核实（arXiv / CVPR page / project page）+ 本地源码

## 核心机制

1. DINOv2 提取 3D 感知特征 → shallow uncertainty MLP 预测逐像素不确定性；
2. 前端 tracking：不确定性作为 dense bundle adjustment (DBA) 权重，抑制动态干扰 + monocular metric depth 辅助位姿；
3. 后端 mapping：渲染 loss 按不确定性加权，增量构建**静态场景**高斯地图；
4. 动态组件被移除，不进入最终重建。

## 关键判定

**Anti-dynamic**。论文摘要："reconstructs a 3D Gaussian map for static elements, effectively removing all dynamic components." 动态物体无显式运动表示，不确定性只是"别信这片区域"的权重。

## 与 RoGS-SLAM 的异同

| | WildGS-SLAM | RoGS-SLAM |
|---|---|---|
| 信号 | DINOv2+MLP（学习） | 光流-重投影一致性（几何） |
| 额外依赖 | metric depth 先验 | 无 |
| mask-free | ✅ | ✅ |
| 处理方式 | 不确定性加权 | Cauchy 软降权 |
