# [2502.03228] GARAD-SLAM: 3D GAussian splatting for Real-time Anti Dynamic SLAM

- **类别**: anti-dynamic（高斯级动态分割）
- **Venue**: ICRA 2025
- **作者**: Mingrui Li, Weijian Chen, Na Cheng, Jingyuan Xu, Dong Li, Hongyu Wang (DLUT / SYSU / U. Macau)
- **来源**: 本地 `/data/arxiv_papers/2502.03228.md`

## 核心机制

1. tracking：直接对 Gaussians 做动态分割（Gaussian pyramid network），映射回前端得动态点标签 → 精确动态移除 + 鲁棒跟踪；
2. mapping：对动态标签高斯施加**渲染惩罚**（网络更新），避免简单剪枝导致的不可逆错误移除；
3. 实时 3DGS-based 动态 SLAM。

## 关键点

- 标题即 "Real-time Anti Dynamic SLAM"——分类无歧义；
- 与 RoGS-SLAM 差异：GARAD 学习高斯级动态分割网络；RoGS 纯几何一致性软降权，无需任何学习网络。
