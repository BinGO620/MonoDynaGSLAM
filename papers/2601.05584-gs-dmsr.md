# [2601.05584] GS-DMSR: Dynamic Sensitive Multi-scale Manifold Enhancement for Accelerated High-Quality 3D Gaussian Splatting

- **类别**: face-dynamic 相邻工作（离线动态场景重建，非 SLAM）
- **Venue**: arXiv 2026（桂林电子科技大学）
- **作者**: Nengbo Lu, Minghua Pan, Shaohua Sun, Yizhou Liang
- **来源**: 本地 `/data/arxiv_papers/2601.05584.md`

## 核心机制

1. **自适应梯度聚焦**：量化高斯属性动态演化过程，识别运动状态差异显著的高斯，差异化优化策略 → 加速收敛；
2. **多尺度流形增强**：隐式非线性解码器 + 显式变形场协同优化，建模复杂变形场景；
3. 合成数据集最高 96 FPS，降低存储与训练开销。

## 关键点

- 不是 SLAM（离线重建），属于 dynamic 3DGS 的 **face-dynamic** 侧；
- 对 RoGS-SLAM 的参考价值有限，但"按运动显著性差异化优化"的思想与我们的 regime 分层有类比空间；
- 收录以保持领域全景完整。
