# [2312.06741] Gaussian Splatting SLAM (MonoGS)

- **类别**: static-base（本项目基座）
- **Venue**: CVPR 2024 (Highlight, Best Demo Award)
- **作者**: Matsuki, Murai, Kelly, Davison (Imperial College London)
- **代码**: https://github.com/muskie82/MonoGS
- **来源**: 本地 `/data/arxiv_papers/2312.06741.md`

## 核心机制

1. 首个基于 3DGS 的实时单目 SLAM（~3fps），Gaussians 为唯一 3D 表示，统一 tracking/mapping/渲染；
2. 相机 tracking：直接对 3D Gaussians 光栅化误差优化位姿，宽收敛域；
3. 几何验证 + 正则化处理增量稠密重建的歧义（transparent/tiny objects）；
4. 可扩展至 RGB-D / stereo。

## 关键点

- 假设静态场景，**无动态处理**：Bonn 动态序列 ATE 严重退化（crowd 86.5cm，RoGS-SLAM 主表数据）；
- RoGS-SLAM 以其为基座，在其上添加四个动态组件（K/R/L/D）。
