# [2602.21644] DAGS-SLAM: Dynamic-Aware 3DGS SLAM via Spatiotemporal Motion Probability and Uncertainty-Aware Scheduling

- **类别**: anti-dynamic（时空运动概率 + 按需语义）
- **Venue**: arXiv 2026（合肥工业大学 / 清华 / 中科大）
- **作者**: Li Zhang, Yu-An Liu, Xijia Jiang, Conghao Huang, Danyang Li, Yanyong Zhang
- **来源**: 本地 `/data/arxiv_papers/2602.21644.md`

## 核心机制

1. 每个高斯维护**时空运动概率 (MP)** 状态，YOLO 实例先验 + 几何线索融合估计并时序更新；
2. 前端：MP 用于动态感知的 correspondence 选择；
3. 后端：MP 引导优化抑制动态伪影；
4. **不确定性感知调度器**：语义按需触发，降低计算开销 → 面向移动/边缘部署（轻量、省电）。

## 关键点

- anti-dynamic：抑制动态伪影、维护静态地图；
- 与 RoGS-SLAM 差异：DAGS 依赖 YOLO 实例先验（非 mask-free）；RoGS 纯几何、零检测器；
- 可借鉴：运动概率的时序更新思想（我们的 L 信号是逐帧的，DAGS 有跨帧累积）。
