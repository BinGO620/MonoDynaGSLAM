## 逐条回应

### R1-M1「核心机制与实现直接矛盾」（Blocking）→ ✅ 已修复

**原问题**：声称"逐 Gaussian 抑制"但实现是全局 opacity 衰减。

**修复**：实现了真正的 selective 机制（scripts/ablate_anti_mode.py, mode=selective）：
1. 每帧渲染残差 → 全局归一化阈值；
2. **高斯中心投影到每帧像素**（einsum w2c + 内参），在残差图上采样该高斯位置的残差；
3. 有效深度观察 ≥3 帧落在高残差区的高斯被**独立衰减** opacity（仅约 1/3 高斯被选中）；
4. 对照 D（随机选同数量高斯衰减）验证选择性本身有效。

**新命名**：residual-guided selective Gaussian opacity decay（不再声称"动态高斯识别"）。

### R2-M1「缺失决定性机制消融」（Blocking）→ ✅ 已完成

**A-F 完整矩阵**（walking_xyz）：

| 组别 | 机制 | PSNR | Δ |
|---|---|---|---|
| A | baseline | 24.03 | — |
| B | 残差调制全局衰减（原实现） | 25.42 | +1.39 |
| C | 固定衰减（无残差） | 24.06 | +0.03 |
| D | 随机高斯衰减（数量匹配 F） | 24.12 | +0.09 |
| E | 逐像素 hard mask | 21.97 | -2.06 |
| F | **残差归因选择性衰减** | **25.00** | **+0.97** |

**结论**：C≈A、D≈A 排除"隐式正则化"替代解释；F>D 证明归因选择有效；E<A 证明像素粒度错误。
诚实补充：F<B——残差信号同时含选择性成分（F 验证）与全局成分（B 利用更多），两者不互补（combined=24.98）。

### R1-M3「结论范围远超证据」→ ⚠️ 部分回应

- **held-out 泛化** ✅：stride=2 半训练协议，F 在 held-out 帧 +0.74 dB（16.61→17.35）；
- **3 seeds** ⏳：进行中，见补充数据；
- **τ 敏感** ⚠️：承认。τ=2.5 在本设置最优，自动选择未实现，列入 limitation。

### R1-M2 / R3-M3「PnP +4.1dB 不可归因 / SLAM 声称被反驳」（Blocking）→ ✅ 已修正

**PnP 四组析因**（walking_xyz）：

| 组合 | PSNR | Δ |
|---|---|---|
| PnP only | 16.2 | — |
| PnP + refine | 19.0 | +2.8 |
| PnP + anti | 16.3 | **+0.1** |
| PnP + refine + anti | 20.3 | +4.1（含 +1.2 协同） |

**修正结论**：原"非 GT 下 anti 提升更大"是归因错误，撤回。修正后：**anti 有效性以位姿质量为前提**——粗糙位姿下单独无效（残差信号被位姿误差淹没），与位姿优化有 +1.2 dB 协同。GT init 下 +1.4 dB 不受影响。**SLAM 改善声称全部撤回**，ATE 恶化如实报告（refine 后 6.0→6.6cm）。

### R3-M1「与动态区域无量化对应」→ ✅ 已量化

Bonn balloon（GT 动态 mask 占比 3.8%）：

| 选择策略 | GT precision |
|---|---|
| selective | **7.9%** |
| random（同数量） | 3.9% |

selective 的动态指向性 = 2× 随机先验。**不声称"识别动态"**，只声称"不一致高斯的选择性抑制，且与动态区域有统计对应（2×）"。绝对 precision 低的原因（深度先验误差/遮挡边界噪声）如实讨论。

### R3-M2「新颖性未建立」→ ⚠️ 部分回应

与 Gassidy（RGB-D，渲染 loss flow 过滤）的区别：单目 + 无学习先验 + 投影归因选择性。承认机制思想同源，定位为**"单目设置下残差引导选择性抑制的系统性机制验证"**（A-F 矩阵 + GT 归因 + 析因），而非新机制发明。与 WildGS 同协议数字对比未完成（列入后续）。

## 最诚实定位（修正版）

**一个组件化单目动态 3DGS 管线 + 对"残差引导选择性高斯抑制"的系统性机制验证**：A-F 消融排除三类替代解释，三序列泛化，held-out 泛化，GT mask 归因（2×），位姿质量边界（析因）。贡献是**机制证据链**而非新 SOTA 方法。
